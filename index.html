Bienvenue 👋

Pour naviguer sans réseau (mode avion), téléchargez d'abord la carte de votre région dans le téléphone : carte + itinéraires + recherche d'adresses.

Cartes hors ligne

Chaque pack contient la carte, le réseau routier (calcul d'itinéraire dans le téléphone) et l'index des adresses. Les packs voisins se raccordent automatiquement aux frontières. Données © contributeurs OpenStreetMap, carte Protomaps.
